# Gen to Gen Foundation Website

## Project Overview

This project is a website developed for the Gen to Gen Foundation. The website provides information about the organisation, its services, and ways for users to make enquiries or contact the organisation.

## Website Pages

- Home
- About Us
- Services
- Enquiry
- Contact

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

The website uses separate folders for CSS, images and JavaScript files.

- `css` - contains the external CSS stylesheet.
- `images` - contains images used on the website.
- `js` - contains JavaScript files.
- HTML files - contain the different pages of the website.

## Part 2 CSS Development

The website was updated using an external CSS stylesheet. The CSS was used to improve the layout, typography, colours, navigation, forms and overall appearance of the website.

Responsive design was also added using relative units and media queries so that the website can adjust to different screen sizes.

## Responsive Design

The website was designed and tested for:

- Desktop screens
- Tablet screens
- Mobile screens

Media queries were used to change the layout, navigation, font sizes and spacing on smaller screens.

## Testing

The website was tested using browser developer tools at different screen sizes.

### Desktop
- Navigation displays horizontally.
- Images remain within the page width.
- Content is displayed clearly.
- Forms and buttons fit correctly.

### Tablet
- Navigation adjusts to the smaller screen.
- Page sections have reduced spacing.
- Text sizes are adjusted for readability.
- Images remain responsive.

### Mobile
- Navigation changes to a vertical layout.
- Content sections use smaller padding.
- Font sizes are reduced where necessary.
- Buttons fit the available screen width.
- Images resize to fit the screen.
